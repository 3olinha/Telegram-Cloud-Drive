## 📖 Como usar a Versão Portátil
1. Extraia a pasta `Portatil` para o seu Pendrive (ou baixe `Telegram_Cloud_Drive_v0.12.exe`).
2. Dê dois cliques em **`Telegram_Cloud_Drive_v0.12.exe`** (ou em **`Abrir_Telegram_Cloud_Drive.bat`**).
3. **Segurança no Pendrive:** Sua conta do Telegram fica vinculada apenas ao computador onde você fez o login. Se você conectar o pendrive em outro computador, o programa pedirá um novo login automaticamente sem expor seus arquivos.
4. Consulte o arquivo **`COMO_USAR_VERSAO_PORTATIL.txt`** dentro da pasta portátil para o passo a passo completo.
